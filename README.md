# CI/CD Pipeline Project

## Project Name
Flask Application CI/CD Pipeline

## Project Description
This project demonstrates Continuous Integration and Continuous Deployment (CI/CD) using GitHub Actions and OpenShift Pipelines.

## Technologies Used
- Python
- Flask
- GitHub Actions
- OpenShift Pipelines
- Tekton
- flake8
- nose

## Project Objectives
- Perform automated code linting.
- Run automated unit tests.
- Build the application container image.
- Deploy the application to OpenShift.
- Verify the deployed application using application logs.

## Pipeline Steps
1. Cleanup
2. Git Clone
3. Code Linting
4. Unit Testing
5. Build Image
6. Deploy Application
